# Amazon Product Registration Skill

Amazon Japanの商品登録、一括登録テンプレート、バリエーション、ブラウズノード、外部マスタ転記を支援するCodex skillです。

## Install

CodexでGitHubリポジトリからskillをインストールする場合：

```text
$skill-installer を使って、このGitHubリポジトリの amazon-product-registration フォルダをインストールしてください。
```

または、リポジトリをcloneし、`amazon-product-registration` フォルダをCodexのskillsディレクトリへ配置します。

## Use

```text
$amazon-product-registration この商品マスタをAmazon一括登録テンプレートへ転記して、未確認項目を分けてください。
```

## Data policy

この公開リポジトリには再利用可能な作業ルールのみを置きます。クライアントの商品データ、価格、認証情報、Seller Centralの処理レポート、成果物は含めません。

Amazon Seller Centralの仕様は更新されるため、実作業では最新テンプレートと公式ヘルプを優先してください。
