# 外部マスタからの転記

## 原則

供給元・クライアントのマスタとAmazonテンプレートでは、同じ情報でも列名、単位、粒度、選択肢が異なる。固定列番号だけに依存せず、元見出し・内部キー・説明文とAmazon属性キーを対応させる。

## 転記しやすい項目

- 管理品番 → ベンダーSKUまたは出品者SKU
- ブランド名 → ブランド
- JAN/EAN/UPC → 製品コードと製品コード種別
- 品名、固有品名、型番 → 商品名・モデル名の素材
- メーカー名 → メーカー
- 特長、用途、材質、仕様 → 箇条書き・商品説明の素材
- セット内容 → 付属品
- 製造国 → 原産国候補
- 電池使用フラグ → 電池要否の候補
- 危険物区分 → 危険物規制の候補
- 質量と単位 → 商品重量の候補

候補値はAmazonの有効値へ正規化し、原文も監査可能な形で残す。

## 自動転記しない項目

根拠が不足する場合、次の項目は空欄または要確認とする。

- 価格、仕入価格、最低・最高価格
- 商品パッケージ寸法とパッケージ重量
- 商品本体寸法とパッケージ寸法の代用
- 材質のAmazon標準値への強引な置換
- サイズ、色、口開き寸法、トルクなど条件付き属性
- 原産国、安全・コンプライアンス、電池、危険物の推測

## 出力区分

各転記値を次のいずれかで管理する。

- 確定：元データに直接の根拠があり、Amazonの有効値とも一致
- 変換：単位・国名・コードなどを明示的なルールで正規化
- 暫定：商品文脈から候補を置いたが確認が必要
- 未入力：根拠不足、または依頼者の判断が必要

元ファイルは変更せず、Amazon登録用ドラフトを別ファイルとして作成する。
